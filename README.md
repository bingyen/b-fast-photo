## 软件能做什么？

- 一次导入并处理大量活动照片。
- AI 自动调整亮度、颜色和对比度。
- 支持全图分析或人脸优先调色。
- 过滤 LED 大屏幕上的假人脸，并保护屏幕高光。
- 识别天空，调整天空亮度、颜色和对比度。
- 一键白平衡、LUT、肌肤亮白、磨皮和降噪。
- 曝光、对比度、饱和度、色温、阴影、高光、暗角和颗粒调整。
- 自动校正角度、裁切、评分、复制设置和批量粘贴。
- 保存项目，下次继续修图。
- 导出当前照片、全部照片或指定评分的照片。

## 第一次使用

1. 点击上方链接下载 EXE。
2. 双击打开 `B-FAST.PHOTO.EDIT.STUDIO.v47.exe`。
3. 点击“添加照片”或“添加文件夹”。
4. 在右侧选择需要的效果。
5. 检查中央预览。
6. 点击“批量导出”，再选择保存位置。

软件会按电脑配置自动选择合适的导出速度，并显示完成张数、总数和预计剩余时间。

## 支持的照片

- 常规图片：JPG、JPEG、PNG、TIFF、WEBP、BMP。
- 相机 RAW：CR2、CR3、ARW、NEF、NRW、RAF、RW2、ORF、DNG、PEF、SRW、X3F 等。

软件会真正读取 Canon、Sony、Nikon、Fujifilm、Panasonic、Olympus／OM System、Pentax 等相机的 RAW 数据。

如果文件夹里同时有同名 RAW 和 JPG，软件会直接询问要导入哪一种，不会混在一起。

## 常用功能

### 仅修此图

默认调整会应用到整批照片。如果只有一张需要特别修改，请先开启“仅修此图”。

### 复制和粘贴效果

可以选择复制哪些调色项目，再粘贴到一张或多张照片。软件不会复制人脸框或人脸识别结果。

### 照片评分

选中照片后按 `1–5` 评分，按 `0` 清除评分。导出时可以只导出指定评分的照片。

### 裁切

支持自由比例、原图比例、1:1、3:2、4:5、16:9 和 9:16，也可以调整角度。按 `Enter` 应用裁切。

### 保存项目

“项目保存”每次都会让你选择保存位置。保存后可以选择开启自动保存。

## 文件重名怎么办？

软件不会覆盖原照片。如果保存位置已有同名文件，会自动添加 `_edited`；再次重名时会继续增加编号。
